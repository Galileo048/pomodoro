# 动画源码合集

## 目录结构

| 编号 | 文件名 | 知识点 | 运行命令 |
|------|--------|--------|----------|
| 01 | 01_匀变速直线运动.py | 匀加速运动v-t图像+小球演示 | `manim -qh 01_匀变速直线运动.py UniformAcceleration` |
| 02 | 02_平抛运动.py | 运动分解+轨迹+小球演示+公式总结 | `manim -qh 02_平抛运动.py ProjectileMotion` |
| 03 | 03_三角函数图像.py | sin/cos变换+振幅+周期+相位 | `manim -qh 03_三角函数图像.py TrigFunctions` |
| 04 | 04_简谐振动.py | 弹簧振子+x-v-a图像+能量守恒 | `manim -qh 04_简谐振动.py SimpleHarmonicMotion` |
| 05 | 05_高中物理大合集.py | 7章完整物理知识体系 | `manim -qh 05_高中物理大合集.py HighSchoolPhysicsComp` |

## 运行说明

1. 确保已安装 Manim 和 MiKTeX
2. 在当前目录打开终端
3. 运行上述命令即可渲染高质量视频
4. 视频输出在 `media/videos/` 目录下

## 依赖

- Python 3.13+
- ManimCE 0.20+
- MiKTeX (LaTeX)
