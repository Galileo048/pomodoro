# AI + Manim 工具参考

## mathanim-desktop（AI驱动桌面工具）
- GitHub: https://github.com/1634594707/mathanim-desktop
- 技术栈：JavaFX + Spring Boot + Manim Community
- 功能：
  - 自然语言/题干输入 → 自动生成 Manim 教学视频
  - GeoGebra 集成
  - TTS 语音配音
  - 多阶段AI生成（解题→分镜→代码）
  - 自动编译检查+重试/回退
- 支持：数学、物理、线性代数、力学
- 中文界面

## manim_gpt（语音+LLM）
- GitHub: https://github.com/Ambier/manim_gpt
- 技术栈：FastAPI + 多模型LLM（DeepSeek/GPT/通义千问）
- 功能：
  - 自然语言/中文语音输入 → Manim动画
  - 多轮编辑
  - 暗色主题Web UI
- 零门槛：不需要 Manim 语法知识

## Askit（实时交互，15⭐）
- GitHub: https://github.com/SwayingWheatfield/Askit.
- 功能：实时交互坐标系 + AI讨论 + Bullet物理引擎
- 需要：24GB+ GPU VRAM

## Visura（文本→动画）
- GitHub: https://github.com/Devansh-Sabharwal/Visura
- 技术栈：TypeScript
- 功能：单文本提示 → 2D Manim动画，无需安装Manim

## generative-manim-physics（研究项目）
- GitHub: https://github.com/marcelo-earth/generative-manim-physics
- 内容：用LLM生成和验证物理动画的研究

## AI-Manim-Studio
- GitHub: https://github.com/dennicLiu/AI-Manim-Studio
- 功能：对话式AI生成数学/物理教学动画
