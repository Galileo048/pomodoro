# AI + Manim 工具参考

## Math-To-Manim（2263⭐）⭐⭐⭐⭐⭐
- GitHub: https://github.com/HarleyCoops/Math-To-Manim
- 中文版: https://github.com/HarleyCoops/Math-to-Manim-CH
- 功能：文本/图片 → Manim 动画 + 学习笔记
- 最成熟的 AI→Manim 工具

## TheoremExplainAgent（1492⭐）
- GitHub: https://github.com/TIGER-AI-Lab/TheoremExplainAgent
- 功能：AI 自动生成定理视频解释（ACL 2025 oral）

## manim_skill（891⭐）
- GitHub: https://github.com/adithya-s-k/manim_skill
- 功能：AI agent 生成 3b1b 风格动画

## generative-manim（842⭐）
- GitHub: https://github.com/marcelo-earth/generative-manim
- 功能：GPT 驱动的 Manim 视频生成

## mathanim-desktop（中文桌面工具）
- GitHub: https://github.com/1634594707/mathanim-desktop
- 技术栈：JavaFX + Spring Boot + Manim Community
- 功能：自然语言/题干输入 → Manim 教学视频，GeoGebra 集成，TTS 配音
- 中文界面

## manim_gpt（中文语音+LLM）
- GitHub: https://github.com/Ambier/manim_gpt
- 技术栈：FastAPI + DeepSeek/GPT/通义千问
- 功能：中文语音输入 → Manim 动画，零门槛

## Askit（实时交互，15⭐）
- GitHub: https://github.com/SwayingWheatfield/Askit.
- 功能：实时交互坐标系 + AI讨论 + Bullet物理引擎
- 需要：24GB+ GPU VRAM

## Visura（文本→动画，8⭐）
- GitHub: https://github.com/Devansh-Sabharwal/Visura
- 功能：单文本提示 → 2D Manim动画

## AI-Manim-Studio
- GitHub: https://github.com/dennicLiu/AI-Manim-Studio
- 功能：对话式AI生成数学/物理教学动画

## generative-manim-physics（研究）
- GitHub: https://github.com/marcelo-earth/generative-manim-physics
- 内容：LLM 生成和验证物理动画
