📐 公式与性质

y = x2
• n > 1：下凸递增，增长加快
• n = 1：直线 y=x
• 0 < n < 1：上凸递增，增长减慢
• n < 0：在 x=0 处有渐近线
• 所有曲线过定点 (1, 1)

📖 知识点

幂函数y=xⁿ过定点(1,1)。指数n的奇偶性影响函数的对称性：n为奇数时关于原点对称，n为偶数时关于y轴对称。

⚠️ 易错提醒

n<0时函数在x=0处趋向无穷（有渐近线），不要忽略负指数的情况。n=0时y=1（常数函数），定义域需注意x不等于0。

🌍 生活应用

面积公式（如圆面积S=πr²中面积与半径的平方关系）、万有引力定律中力与距离的反比关系（n=-2）、物理学中的各种幂次定律。
