==PARA:以下是2020铝型材框架的详细组装步骤，配合图示说明每个关键操作。所有四个实验共用同一框架结构。==

==PARA:步骤1：铝型材切割标记==

    卷尺测量法（推荐）：
    ┌─────────────────────────────────────────┐
    │  铝型材端面                                │
    │  ┃                                         │
    │  ┃←── 80cm (立柱A1-A4) ──→┃               │
    │  ┃         ↑               ┃               │
    │  ┃    用记号笔             ┃               │
    │  ┃    在四周画线           ┃               │
    │  ┃    ↓                   ┃               │
    │  ┃   ━━━━  ← 切割线（四周都要画）          │
    │  ┃                                         │
    └─────────────────────────────────────────┘

    切割要点：
    ① 在型材四个面都画切割线，确保锯切垂直
    ② 使用型材切割器（或钢锯+切割盒）
    ③ 切割后用锉刀打磨端面毛刺

==PARA:步骤2：角码连接顺序（关键！）==

    正确的组装顺序：先立柱 → 后横梁 → 最后附件

    第一步：竖起四根立柱（A1-A4）
                A1          A2
                ┃           ┃
                ┃           ┃
                ┃           ┃
                ┃           ┃
               (地面)

    第二步：用角码连接前后横梁（B1-B4）
                A1          A2
                ┃──B1───────┃──B2
                ┃  (角码↑)  ┃
                ┃           ┃
                ┃──B3───────┃──B4
               (地面)

    第三步：连接左右横梁（C1-C4）
          俯视图：
          ┌────C1────┐
          │          │
          A1        A2
          │          │
          ├────C2────┤

    角码安装方法：
    ┌─────────────────────────────┐
    │        T型螺母               │
    │    ┌───┐                    │
    │    │ T │ ← 放入型材槽内      │
    │    └─┬─┘                    │
    │      │ M5螺丝               │
    │    ┌─┴─┐                    │
    │    │角码│ ← L型角码          │
    │    └───┘                    │
    │                             │
    │  操作：① 把T型螺母滑入槽内   │
    │        ② 对齐角码的孔       │
    │        ③ 拧入M5×8螺丝       │
    │        ④ 用内六角扳手拧紧    │
    └─────────────────────────────┘

    使用手机水平仪APP：
    ┌────────────────────────────────────┐
    │                                    │
    │   把手机放在框架顶面横梁上         │
    │                                    │

  □ 顶面水平（水平仪气泡居中）

==SECTION:CIRCUIT_WIRING==
==TITLE:【详细图示】电磁铁驱动电路面包板接线指南==

==PARA:以下是在830孔面包板上搭建MOSFET驱动电路的详细步骤。这个电路用于控制电磁铁的通断，实现小球的精确释放。==

==PARA:步骤1：认识面包板内部结构==

    830孔面包板俯视图：
    ┌────────────────────────────────────────────┐
    │  +  ━━━━━━━━━ 电源正极(红色) ━━━━━━━━━  +  │
    │  -  ━━━━━━━━━ 电源负极(蓝色) ━━━━━━━━━  -  │
    │                                            │
    │  a b c d e │ │ f g h i j                   │
    │  ○ ○ ○ ○ ○ │ │ ○ ○ ○ ○ ○  ← 第1行         │
    │  ○ ○ ○ ○ ○ │ │ ○ ○ ○ ○ ○  ← 第2行         │
    │  ○ ○ ○ ○ ○ │ │ ○ ○ ○ ○ ○  ← ...           │
    │  ...每5列一组，中间有隔离槽...              │
    │  ○ ○ ○ ○ ○ │ │ ○ ○ ○ ○ ○  ← 第30行        │
    │                                            │
    │  +  ━━━━━━━━━ 电源正极 ━━━━━━━━━━━━  +     │
    │  -  ━━━━━━━━━ 电源负极 ━━━━━━━━━━━━  -     │
    └────────────────────────────────────────────┘

    重要规则：
    · 同一行的 a-e 孔是连通的（水平方向）
    · 同一行的 f-j 孔是连通的
    · a-e 和 f-j 之间不连通（中间有隔离槽）
    · 上下两半的电源轨道是连通的（垂直方向）

==PARA:步骤2：识别元件引脚==

    MOSFET (IRF520/IRF540) 引脚（面对正面，标签朝向自己）：
         ┌─────────┐
         │  IRF520  │
         │         │
         └┤G    D ├┘
          │       │
          └──S────┘
    G = Gate（栅极）    → 接GPIO18通过电阻
    D = Drain（漏极）   → 接电磁铁负极
    S = Source（源极）  → 接GND

    续流二极管 (1N4007)：
    银色环的一端是负极（阴极）
    ──|◁──  三角形指向电流方向
      ↑
    银色环（负极）

    电磁铁接线：
    红线 → +12V
    黑线 → Drain（MOSFET的D极）

    ┌──────────────────────────────────────────────┐
    │  + ━━━━━━━━━━━ 12V正极 ━━━━━━━━━━━━━━ +     │
    │  - ━━━━━━━━━━━ GND ━━━━━━━━━━━━━━━━━━ -     │

    │                                              │
    │  ┌───── 行1 ──────────────────────────┐      │
    │  │ 1kΩ电阻: a1 ──e1                   │      │
    │  │    (a1接GPIO18)                     │      │
    │  │    (e1接MOSFET Gate)                │      │
    │  └────────────────────────────────────┘      │
    │                                              │
    │  ┌───── 行5 ──────────────────────────┐      │
    │  │ MOSFET: a5=Gate  b5=Drain  c5=Source│     │

    │                                              │

    │    红线 → +极轨道 (12V)                      │

    │                                              │
    │  + ━━━━━━━━━━━ 12V正极 ━━━━━━━━━━━━━━ +     │
    │  - ━━━━━━━━━━━ GND ━━━━━━━━━━━━━━━━━━ -     │
    └──────────────────────────────────────────────┘

    走线颜色建议：
    红色线 = 电源正极（12V, 5V）
    黑色线 = GND
    黄色线 = 信号线（GPIO18 → 1kΩ → Gate）
    蓝色线 = 传感器信号线

==PARA:光电门是测量周期和速度的关键传感器。安装精度直接影响实验数据质量。以下是详细的安装和校准步骤。==

==PARA:步骤1：光电门对准平衡位置（阻尼振动/单摆实验）==

    原理：光电门应在物体通过平衡位置时触发

    阻尼振动实验：
                    ┌─── 弹簧
                    │
                    ▼
                 ┌─────┐
                 │振子+ │  ← 最高点
                 │遮光片│
                 └─────┘
                    │
                    │   振动范围
                    │
            ━━━━━━━━┿━━━━━━━━  ← 平衡位置（弹簧自然长度处）
                    │
                    │
                 ┌──┴──┐
                 │光电门│ ← 安装在这里！
                 │ ↑↓  │    遮光片经过时触发
                 └─────┘

    单摆实验：
          固定点
            ●━━━━━━━━━┓
                      ┃ 摆线
                      ┃
            ←θ    ●   ┃  ← 摆球（平衡位置）
                   ↑   ┃
              光电门位置 ┃
              ┌───┐    ┃
              │光电门│  ┃
              └───┘
            平衡位置

    校准方法：
    ① 让振子/摆球静止在平衡位置
    ② 调节光电门高度，使遮光片/摆球中心对准光电门的红外发射管
    ③ 用手缓慢拨动物体通过光电门，观察ESP32的LED是否闪烁
    ④ 如果LED不闪烁：调节灵敏度旋钮或检查接线

==PARA:步骤3：释放质量判断（好vs坏）==

    好的释放 vs 坏的释放：

    好的释放 ✓                坏的释放 ✗
    ┌──────────┐              ┌──────────┐
    │     ●    │ ← 轨迹1      │     ●    │ ← 轨迹1
    │    /     │              │    /     │
    │   /      │              │   //     │ ← 轨迹2（偏了）
    │  /       │              │  /       │
    │ /        │              │ /        │
    │●         │              │●         │
    └──────────┘              └──────────┘
    每次轨迹几乎重合            每次轨迹不同
    R² > 0.999                R² < 0.99

    判断方法：
    ① 连续释放5次，目测轨迹是否重合
    ② 分别拟合，比较5次的v₀值，标准差应<1%
    ③ 如果一致性差，检查：
       · 舵机：是否有释放时的推力
       · 电磁铁：是否有剩磁延迟释放
       · 导轨：是否不水平或有摩擦

    │ 光电门/传感器2│ GPIO35 │ 输入(ADC)│ 全部实验               │
    │ 备用传感器3   │ GPIO36 │ 输入(ADC)│ 自由落体（3个光电门）  │
    │ 板载LED       │ GPIO2  │ 输出     │ 状态指示（全部）       │
    │ 串口TX        │ GPIO1  │ 输出     │ 调试（全部）           │
    │ 串口RX        │ GPIO3  │ 输入     │ 调试（全部）           │
    │ ADC电压测量   │ GPIO33 │ 输入(ADC)│ 欧姆定律               │
    └──────────────┴────────┴──────────┴───────────────────────┘

    禁止使用的GPIO：
    GPIO6-11  → 连接内部Flash，使用会导致崩溃！
    GPIO0     → 启动模式选择，仅作BOOT按钮
    GPIO12    → 启动时检测电平，可能引起启动失败
